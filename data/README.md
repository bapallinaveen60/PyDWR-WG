# Data Directory Layout for PyDWR-WG

This directory houses radar volume scans, SRTM topography, surface microphysical measurements, and satellite datasets. Raw binary files are ignored by git; place datasets in their respective subdirectories as outlined below:

## Directory Structure

- `raw/imd_radars/`:
  - `mumbai/`: Raw volume scans (Rainbow / IRIS / NetCDF) from S-band DWR Mumbai (Colaba / Veravali).
  - `goa/`: Raw volume scans from S-band DWR Goa.
  - `kochi/`: Raw volume scans from S-band DWR Kochi.
- `raw/mandhardev_xband/`: Raw scans from Mandhardev X-band radar (18.04°N, 73.86°E, 1.3 km MSL).
- `raw/srtm_dem/`: 30-meter Shuttle Radar Topography Mission (SRTM) 1-arc-second DEM geotiffs covering $14^\circ\text{N}-20^\circ\text{N}, 71^\circ\text{E}-76^\circ\text{E}$.
- `raw/hacpl_disdrometer/`: 1-minute drop size distribution (DSD) data from JWD, 2DVD, and MRR-2 vertical profiles at HACPL Mahabaleshwar ($17.92^\circ\text{N}, 73.60^\circ\text{E}, 1378\text{ m MSL}$).
- `raw/insat3dr/`: INSAT-3DR/3DS Imager multispectral L1B/L2 files (TIR1, TIR2, MIR, WV) and collocated ERA5 atmospheric state.
- `clutter_maps/`: Pre-monsoon dry-weather composited static clutter frequency matrices.
- `blockage_masks/`: Precomputed 3D ray-tracing beam blockage fractions (BBF) and beam centerline heights ($h_{beam}$).
- `synthetic_scip/`: Paired training sets generated by the Semi-Synthetic Clutter Injection Pipeline (SCIP).
- `processed/`: Calibrated polar arrays ($1000 \text{ gates} \times 360 \text{ radials} \times 10 \text{ channels}$) stored in NetCDF4 / Zarr.
- `satellite_labels/`: 1 km × 1 km gridded 5-class precipitation ground-truth masks for INSAT-3DR retraining.
